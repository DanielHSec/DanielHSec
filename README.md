Gosto de entender como as coisas funcionam — da aplicação ao servidor — e transformar tarefas repetitivas em processos mais simples, confiáveis e automatizados.

- **Desenvolvimento:** aplicações web, ferramentas internas, scripts e automações com Python, Flask e JavaScript.

## 🚀 Projetos em destaque

### 🌐 [VerificarSite — Verificador de Confiabilidade de Sites](https://github.com/DanielHSec/VerificarSite)

**Projeto público · Python · Flask · Selenium · HTML/CSS**

Aplicação web que recebe URLs e utiliza automação de navegador para apoiar a análise de informações sobre sites, apresentando os resultados em uma interface web.

**[Ver repositório →](https://github.com/DanielHSec/VerificarSite)**

### 🖥️ Central de TI e Governança

**Projeto privado · React · Vite · Supabase · PostgreSQL**

Sistema interno voltado à organização de operações de TI, reunindo processos como inventário de equipamentos, chamados, acompanhamento de SLA, orçamentos, mudanças e relatórios. O desenvolvimento considera autenticação, controle de acesso e rastreabilidade das operações.

### ⚙️ Automação de Processos de Saúde Ocupacional

**Projeto colaborativo privado · Python · Flask · JavaScript · Automação web**

Desenvolvimento de ferramentas para reduzir trabalho manual em rotinas administrativas: cadastro e validação de dados, organização de solicitações, fluxos de exames ocupacionais e preenchimento assistido de sistemas. O projeto evolui por etapas, com foco em confiabilidade e integração de processos.

### 📄 Organizador de PDFs Ocupacionais

**Projeto independente · Python · OCR · Manipulação de PDFs · Interface gráfica**

Ferramenta para identificar, classificar e organizar documentos como ASOs, fichas clínicas e exames complementares, buscando diminuir tarefas repetitivas de conferência e renomeação de arquivos.

### 🏠 Homelab e Infraestrutura Self-hosted

**Laboratório contínuo · Debian · Docker · Redes · Monitoramento**

Ambiente de testes com servidores Linux, contêineres, automações, serviços locais e acesso remoto. Utilizado para praticar implantação, administração, observabilidade, resolução de incidentes e boas práticas de infraestrutura.

**Tecnologias exploradas:** Docker, Portainer, Home Assistant, MQTT, Uptime Kuma, Apache Guacamole, AdGuard Home e Tailscale.

> Alguns projetos têm repositórios privados por envolverem ferramentas de uso interno. As descrições públicas apresentam apenas objetivos e tecnologias gerais.
